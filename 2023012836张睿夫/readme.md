
## 作业一：银行家算法Python实现

本程序通过Python语言模拟实现了操作系统中的银行家算法，用于检测系统安全状态和处理进程资源请求。

## 文件说明:

  - banker_algorithm.py：主程序文件，封装了银行家算法的核心逻辑，包括：
  - 安全检测算法（`safety_check`函数）
  - 资源请求处理（`check_request`函数）
  - 系统状态显示（`print_state`函数）
  - 安全序列查找（`find_safe_sequence`函数）

 ## 如何运行

1. 确保您的环境中安装了Python 3.x和NumPy库
2. 在命令行中运行程序：
   python banker.py
3. 按照提示输入系统初始状态信息
4. 选择操作模式进行测试

## 功能说明

本程序实现了以下功能：

1. **系统状态初始化**：
   - 输入资源种类数量、剩余资源矩阵
   - 输入进程数量及各进程的最大需求矩阵和已分配矩阵
   - 自动计算需求矩阵（Need = Max - Allocation）

2. **系统状态显示**：
   - 以表格形式展示所有进程的Max、Allocation和Need矩阵
   - 显示当前剩余资源向量

3. **安全状态检测**：
   - 自动检测系统是否处于安全状态
   - 如果安全，输出一个安全序列

4. **资源请求处理**：
   - 处理特定进程的资源请求
   - 检查请求是否合法（不超过进程需求和可用资源）
   - 模拟分配并检测系统安全性
   - 自动回滚不安全的请求

## 输入格式

程序运行时需要依次输入以下信息：

1. 资源种类数量（整数）
2. 剩余资源矩阵（空格分隔的整数）
3. 进程数量（整数）
4. 每个进程的最大需求矩阵（空格分隔的整数）
5. 每个进程的已分配矩阵（空格分隔的整数）

## 注意事项

1. 已分配矩阵不能超过最大需求矩阵
2. 资源请求不能超过进程需求或可用资源
3. 程序会自动处理不安全的请求，不会实际分配资源
4. 使用NumPy库进行矩阵运算，确保安装依赖：`pip install numpy`
